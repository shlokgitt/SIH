# Marketplace Module — owned by: [Shrijan]

Build the plant listing, browse, and bulk order UI here.

## What to build
- Batch browse/listing page (pulls from `GET /api/marketplace/batches`)
- Batch detail page (`GET /api/marketplace/batches/:id`)
- Order placement form (`POST /api/orders`)
- Distance/location-based sort or filter UI

## API reference
See `backend/README.md` → Marketplace section for exact request/response shapes.

## Rules
- Only edit files inside this folder.
- Shared buttons/cards/layout go in `../shared/` instead — ask the UI/UX lead to add them there.
